Create the ITERA GitHub App

This page sends the App manifest below to GitHub. GitHub then shows a confirmation page for the devfellowship organization. Click Create GitHub App there.

GitHub then redirects to .../connect/github/app-created?code=.... That page can show a 404: copy the full address from the address bar and send it to the operator who runs step 3 of README.md. The code expires in 1 hour.
